# Byggt om inl_3 i React
## Filmlista
### DA395B

Uppgiften har gått ut på att bygga om en tidigare uppgift som först utvecklades med jQuery.  
Målet var att återskapa samma funktionalitet med React för att öva på komponentbaserad utveckling.

1. **Öpnna** valfri terminal
2. **navigera** till projektmappen
3. **Installera** paket: `npm install`
4. **starta** servern: `npm run dev`

### relevanta filer:
